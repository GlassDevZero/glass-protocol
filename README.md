# GLASS: GNU LED Adaptive Stadium Standard

**Author:** GlassDevZero
**License:** GNU GPL v3
**Hardware:** ESP32-H2 (Auracast Ready)

## Vision
GLASS is an open-source protocol designed to turn entire stadiums into massive, synchronized displays using LED wearables (bracelets, vests, drones). 

## Key Features
* **Speed of Light Mode:** Zero-latency execution for instant visual effects.
* **Auracast Sync:** Utilizing Bluetooth LE Audio for massive broadcast reach.
* **GNU Philosophy:** Free to use, modify, and distribute. Forever.

## Technical Architecture
The protocol is defined in `GLASS_Core.h`. It focuses on low-overhead UDP-like packets broadcasted over Auracast.
